# SPWM-Inverter-12v-to-220v
Hardware desing and LTspice simulation of a 12v to 220v 60hz pure sine wave inverter using an SPWM driven H bridge and step up transformer 


This repo contains the circuit schematics, ltspice simulation files  and hardware documentation for a custom made solid state dc to ac inverter. The system is desinged to convert a standard 12v dc input into a clean 220v 60hz pure sin wave AC output.
The core design relies on an H-bridge topology driven by sinusoidal pulse width modulation logic paired with an LC output filer and step up transformer. Currently the repo only holds the verfied pspice simulations.
